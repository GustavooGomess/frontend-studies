## 🧠 O que já estudei

<details>
<summary><b>🔧 Ambiente e versionamento</b></summary>

- Controle de versão × backup e versionamento semântico (`MAJOR.MINOR.PATCH`)
- Git, branches, tags e boas práticas
- Node.js, NPM e criação de projeto React
- Deploy contínuo com Vercel

</details>

<details>
<summary><b>⚛️ Frameworks e bibliotecas</b></summary>

- Framework × biblioteca (inversão de controle)
- React, Vue, Angular e Next.js
- Componentização e comparativo entre as tecnologias

</details>

<details>
<summary><b>🌐 APIs e back-end para o front</b></summary>

- REST, HTTP, métodos (GET, POST, PUT, PATCH, DELETE) e endpoints
- JSON como formato de troca de dados
- API com Express.js, documentação no Postman e deploy no Render

</details>
